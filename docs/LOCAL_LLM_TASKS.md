# ⚙️ Simple Routing Rule

Use Local when:

* Small input
* Simple transformation or explanation

Use Hybrid when:

* Needs retrieval (RAG)
* Medium reasoning

Use Cloud when:

* Large context
* Complex reasoning
* High accuracy required

---

# ✅ Key Notes

* Small LLMs are best at:

  * Formatting
  * Transformations
  * Short explanations

* Weak at:

  * Deep reasoning
  * Large context
  * Complex system understanding
